# House Price Prediction System

An AI-powered House Price Prediction System built using Machine Learning, Flask, and Python.

This project predicts house prices based on:
- Location
- BHK
- Bathrooms
- Square Feet Area

The application uses a trained Ridge Regression model and provides predictions through an interactive web interface.

---

## Features

- House price prediction using Machine Learning
- Interactive Flask web application
- Location-based prediction
- User-friendly UI
- Real-time prediction results

---

## Tech Stack

- Pandas

- Scikit-learn
- Flask
